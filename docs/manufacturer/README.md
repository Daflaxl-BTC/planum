# Planum Sticker — Hersteller-Anfrage

Dieser Ordner enthält das vollständige Konzept und das Anschreiben für die Anfrage an einen Alibaba-Hersteller für QR/NFC-Sticker.

## Dateien

- **Planum_Konzept_Sticker.html** — Konzept-Dokument (Web, mit allen 3 Designvarianten)
- **Planum_Konzept_Sticker.pdf** — Konzept-Dokument (zum Anhängen an die Anfrage)
- **Planum_Anfrage_Hersteller.docx** — Anschreiben (Deutsch + Englisch in einem Dokument)
- **Planum_Anfrage_Hersteller.pdf** — Anschreiben als PDF

## Verwendung

1. Designvariante final entscheiden (A: Leaf Crown / B: Forest Frame / C: Monstera Hug)
2. Im DOCX die Platzhalter `[Hersteller-Name]`, `[Ansprechpartner]`, `[Firmenanschrift]`, `[Stadt, Provinz, China]` ausfüllen
3. PDF + Konzept-PDF an die Alibaba-Nachricht anhängen
4. An 3–5 Hersteller parallel senden, Angebote vergleichen

## Erstbestellung (Sample-Run)

- 25 Pakete Standard (nur QR) = 500 Sticker
- 25 Pakete Premium (QR+NFC) = 500 Sticker
- **Gesamt: 50 Pakete / 1.000 Sticker**
